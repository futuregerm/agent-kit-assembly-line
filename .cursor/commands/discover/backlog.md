# backlog

Discover-track. Turn an intake summary into an ordered backlog of weighted slices. Plan-only.

Follow `.claude/skills/backlog/SKILL.md`, `docs/agent/README.md` (discover stage), and `docs/agent/classes.md` (weights). Do not duplicate the process.

Quick path:
1. Read the intake **decision log** + summary. No log for a new scope? Go back to `intake`.
2. Break work into small shippable slices — prefer many thin cards.
3. Each slice needs **Done when / Depends on / Weight / owning decision-log section** (`light` / `full` / `write-security`; when unsure, heavier).
4. Write to `.agent/slices/<scope>-slices.md`.
5. Stop for human approval before any lock.
