# intake

Discover-track entry. Turn raw business input into a structured summary. Plan-only.

Follow `.claude/skills/intake/SKILL.md` and `docs/agent/README.md` (discover stage). Do not duplicate the process — read those.

Quick path:
1. Read `.agent/_imports/` + `docs/core/` + `.agent/project_config.md`.
2. Produce a structured summary (themes, candidate work, risks, open questions).
3. Lock a **decision log** (headline question, locked rules, out-of-scope) — the intake exit. Ask one decision at a time when non-trivial. Reuse existing published law as the log when a scope already has one.
4. No code. Hand off to `backlog`.
